# 풀빌라 가족오락관

아이와 어른이 섞인 두세 팀이 풀빌라에서 즐기는 가족오락관 진행 웹앱입니다.
**인터넷도, API 키도 없이 19개 라운드가 전부 돌아갑니다.** 문제는 앱 안에 들어 있습니다.

## 주요 기능

- 2팀 또는 3팀 대결, 팀마다 문항 수가 정확히 균등
- 19개 라운드 중 원하는 것만 골라 진행
- 라운드가 많아서 화면/말·몸/안 한 것 필터와 🎲 랜덤 선택 제공
- 실수로 점수를 확정했으면 마지막 결과 취소, 총점 직접 수정 가능
- 재미없으면 라운드 중간에 끊기 — 단, 모든 팀이 같은 횟수를 마친 지점에서만
- **모든 라운드의 팀당 최대 점수가 24점 안팎**이라, 어떤 라운드를 고르든 무게가 비슷합니다
- 누적 점수판, 라운드 재도전(점수 교체 또는 추가 선택)
- 최근에 낸 문제를 기억해서 여러 판을 해도 잘 겹치지 않음
- localStorage 진행 상태 저장
- Web Audio 효과음, `canvas-confetti` 축하 효과
- 배경음악 6곡 (`public/audio`) — 켤 때만 내려받고, 섞어서 이어 재생하며 효과음이 나면 잠깐 작아짐
- 모바일 우선 UI, 색약 대응(색+모양), 모션 줄이기 설정 반영, 라운드 중 화면 꺼짐 방지

## 라운드

| 라운드 | 방식 | 내용 |
|---|---|---|
| 스피드 퀴즈 | 화면 | 2분 동안 설명하고 맞히기 (1개당 1점) |
| 흐릿한 이미지 | 화면 | 점점 선명해지는 그림 맞히기 (우리 사진도 섞임) |
| 초성 퀴즈 | 화면 | 초성만 보고 외치기 (글자 수만큼 시간·점수) |
| 이모지 퀴즈 | 화면 | 이모지로 노래·영화·캐릭터·속담 맞히기 |
| 거짓말 탐지기 | 화면 | 진실인지 거짓인지 고르기 |
| 기억 도둑 | 화면 | 잠깐 본 그림 중 사라진 하나 찾기 |
| 순서 맞추기 | 화면 | 섞인 네 장면을 순서대로 되돌리기 |
| 열두 획 화백 | 화면 | 글자 없이 12획으로 그려서 맞히게 하기 (단어) |
| 멈출까? 짐칸 6 | 화면 | 짐을 더 실을지 출발할지, 6을 넘기면 0점 |
| 수상한 한 칸 | 화면 | 규칙을 혼자 어긴 칸 찾기 |
| 말하면 지는 인터뷰 | 말·몸 | 상대가 금지어를 말하게 유도하기 (거짓말 들통나면 상대 +8) |
| 눈치 올인 | 말·몸 | 다른 팀과 안 겹치는 답 고르기 (올인 1회) |
| 열거 대결 | 말·몸 | 30초 안에 정해진 개수 대기 |
| 거꾸로 말하기 | 말·몸 | 들은 단어를 외워서 거꾸로 말하기 |
| 한말 두 얼굴 | 말·몸 | 같은 단어를 다른 뜻으로 쓴 문장 만들기 |
| 세 팀 금고 | 말·몸 | 팀마다 단서 하나씩, 다 같이 금고 열기 (협동) |
| 고요 속의 외침 | 말·몸 | 입모양만 보고 단어 전달하기 |
| 몸으로 말해요 | 말·몸 | 2분 동안 몸짓으로만 표현하기 (1개당 2점) |
| 수영장 보물찾기 | 말·몸 | 동전 30개, 60초 (순위 24/16/8점) |

## Anthropic API 키 (선택 사항)

키를 넣지 않아도 모든 라운드가 그대로 돌아갑니다. 키를 넣으면 라운드마다 Claude가
문제를 새로 만들어 앱 안의 문제 위에 얹습니다. 모델은 `claude-sonnet-5`를 먼저 쓰고,
실패하면 `claude-haiku-4-5`로 넘어갑니다. (문제 만들기에는 이 정도로 충분하고 요금이 쌉니다)

- **Claude Pro·Max 구독과 API 요금은 별개입니다.** 키를 쓰면 쓴 만큼 API 요금이 따로 청구됩니다.
- 키는 배포 서버에 저장되지 않고 브라우저의 `localStorage`에만 저장됩니다.
- 호출이 실패하거나 20초 안에 응답이 없으면 자동으로 앱 안의 문제로 넘어갑니다.
- 키는 [console.anthropic.com](https://console.anthropic.com/) → API Keys에서 만들 수 있습니다.

## Vercel 배포

1. GitHub 등에 이 프로젝트를 올립니다.
2. Vercel에서 새 프로젝트를 만들고 저장소를 연결합니다.
3. Framework Preset은 Vite, Build Command는 `npm run build`, Output Directory는 `dist`입니다.

React Router 새로고침을 위해 `vercel.json`에 SPA rewrite가 포함되어 있습니다.
